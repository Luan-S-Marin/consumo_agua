# 📝 Projeto: Consumo de água 💧

## Linguagem: Python 🐍

Sobre: Este projeto foi criado para classificar o consumo mensal de um Imóvel com base no gasto em metros cubicos

O programa solicita que o usuário digite o tipo de sua residencia (casa/apartamento/comercial) e depois pede para digitar o consumo mensal em metros cubicos. A classificação do consumo varia entre econômico, moderado e excessivo.
